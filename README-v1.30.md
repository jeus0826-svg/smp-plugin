# SMP v1.30 변경 사항 (Paper 1.19.4, Java 17)

- 신호기 구매 가격: 10, 20, 30, ... 다이아몬드 (플레이어별 기존 구매 횟수 유지)
- `/teamstorage` (`/teamchest`, `/팀창고`): 같은 팀이 공유하는 54칸 추가 창고. 개인 인벤토리는 변경되지 않음. `plugins/SMP/state.yml`에 저장.
- 신호기 설치 전: 침대 리스폰을 우선 존중. 유효한 침대가 없다면 팀 시작 위치. 신호기 설치 후: 팀 신호기 근처로 리스폰.
- 방벽 기둥: 신호기 X/Z 바로 위에만 생성. 주변 4개 기둥 제거. **방벽은 불투명하므로 바닐라 신호기 광선을 막을 수 있음**.
- 네더라이트 주괴 주손 우클릭: 같은 차원에서 가장 가까운 다른 팀 플레이어 방향으로 최대 32블록 불꽃 궤적을 표시. 같은 차원에 다른 팀 플레이어가 없으면 다른 차원에서 사용하라는 안내. 주괴 소모 없음.
- 기존 데이터는 보존하지만 배포 전 `world*` 및 `plugins/SMP/state.yml` 백업 필수.
- GitHub Actions 빌드 결과를 확인해야 하며 실제 서버 검증은 아직 수행되지 않음.
