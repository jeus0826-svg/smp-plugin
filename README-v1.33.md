# SMP v1.33 변경사항

- 네더라이트 파편 대신 **망원경(SPYGLASS) 우클릭**으로 같은 차원의 가장 가까운 다른 팀 플레이어 방향을 추적합니다.
- 망원경은 소모되지 않습니다. 추적에 성공하면 **3분(180초) 쿨타임**이 시작됩니다.
- 불꽃은 약 **4블록 길이**, **10초 동안** 갱신됩니다.
- 같은 차원에 추적 대상이 없으면 다른 차원에서 사용하라는 안내를 표시하고 쿨타임은 시작하지 않습니다.
- 이전 v1.32 소스의 팀 공유 창고 불러오기 코드 위치 오류(y 변수 컴파일 오류)를 수정했습니다.
- 기존 기능과 서버 데이터 저장 구조를 유지합니다.

GitHub Actions 빌드 및 서버 테스트가 필요합니다.
