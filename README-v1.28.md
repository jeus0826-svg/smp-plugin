# SMP v1.28 (Paper 1.19.4 / Java 17)

기존 v1.27의 팀·신호기·전투·인챈트 규칙을 유지하면서 팀 합류/색상/리스폰 기능을 수정한 **소스 프로젝트**입니다.

## 변경사항
- `/teamset <팀장> <팀원1> ...`: 게임 시작 이후에도 팀원 추가 가능. 오프라인 닉네임도 입력 가능.
- 게임 진행 중 온라인 팀원을 추가하면 그 팀의 신호기(있다면) 또는 기존 팀 스폰으로 이동.
- 처음 접속하는 오프라인 팀원은 닉네임에 대응하는 UUID로 팀을 찾아 해당 팀 위치로 이동.
- 팀장 신호기 설치 후 온라인 팀원 즉시 신호기 근처로 이동. 이후 사망 리스폰도 신호기 우선, 신호기 없으면 팀 시작 지점.
- 팀별 스코어보드 색상, 같은 팀은 같은 색상. 색상은 state.yml에 저장.
- `/startgame` 이전 팀 설정은 유지.

## 오프라인 닉네임 유의
`Bukkit.getOfflinePlayer(name)`을 사용하므로 온라인 모드에서 한 번도 서버에 들어오지 않은 플레이어의 UUID 조회는 서버/프로필 캐시에 따라 실패하거나 부정확할 수 있습니다. 가능하면 해당 사용자의 정확한 Minecraft Java 닉네임을 입력하고 첫 접속 시 팀 배정을 확인하세요. 서버 online-mode를 바꾸면 UUID가 달라질 수 있습니다.

## 빌드
GitHub 저장소에 ZIP의 폴더 구조 그대로 업로드한 후 Actions의 Build SMP Plugin을 실행합니다. 빌드 성공 후 Artifacts의 SMP-1.19.4-JAR을 다운로드하여 압축을 풀고 서버 `plugins/SMP-1.19.4.jar`로 교체하세요. 서버 종료 및 `plugins/SMP/state.yml` 백업 후 작업하세요.

## 테스트
1. `/version SMP` → 1.28.0
2. `/teamset Leader Member` (Member가 오프라인이어도 실행)
3. `/startgame` → Leader의 스폰 확인
4. Member 접속 → 같은 팀 스폰 확인
5. 신호기 설치 → 온라인 팀원 이동 확인
6. Member 사망 → 신호기 근처 리스폰 확인
7. 다른 팀 구성 → 이름 색상 구분 확인

**검증 상태:** 소스 수정 완료. 이 환경에서 Maven 컴파일 및 실제 게임 내 동작은 검증되지 않았습니다.
