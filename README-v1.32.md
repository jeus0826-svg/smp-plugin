# SMP v1.32 변경사항

- 신호기 미설치 나약함 유예시간을 1시간에서 **실제 시간 24시간**으로 변경.
- `/startgame` 당시 참가자는 게임 시작 시점부터 24시간.
- 게임 시작 후 최초 참가자는 **최초 접속·초기화 시점부터** 24시간. 접속 종료·서버 재시작으로 시간이 초기화되지 않음.
- 팀 신호기가 설치되어 있거나 설치 이력이 있는 팀은 기존 정책에 따라 미설치 페널티 면제.
- 참가 시간은 `plugins/SMP/state.yml`의 `playerGraceStartedAt`에 저장.
- 이전 버전에서 이미 참여한 플레이어는 기록된 최초 접속 시각이 없으므로 **기존 게임 시작 시각**을 기준으로 계산.
- 이전 v1.31 기능은 유지.

> 소스 수정본이며 컴파일 및 실제 서버 테스트는 별도로 필요합니다.
