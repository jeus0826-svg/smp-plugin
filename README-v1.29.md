# SMP v1.29 (Paper 1.19.4 / Java 17)

## 접속 위치 수정
- 이미 게임에 참여한 플레이어가 접속 종료 후 재접속하면 마지막 로그아웃 위치에서 시작합니다. 신호기나 팀 시작점으로 강제 이동하지 않습니다.
- 게임 시작 후 `/teamset`으로 새 팀에 배정된 온라인 플레이어는 즉시 팀 위치로 이동합니다.
- 오프라인 상태에서 팀에 배정된 플레이어는 다음 접속 시 **한 번만** 팀 위치로 이동합니다. 이동 성공 시 대기 기록을 삭제합니다.
- 처음 참여하는 플레이어는 기존 팀 시작 위치/신호기 규칙을 따릅니다.
- 사망 후 리스폰, `/beacontp`, 신호기 설치 시 팀 이동 규칙은 변경하지 않았습니다.
- `plugins/SMP/state.yml` 기존 데이터 키는 유지하고 `pendingTeamTeleports`만 추가했습니다.
- v1.28 소스의 팀 색상 ChatColor 컴파일 오류 수정도 포함했습니다.

## 설치
1. GitHub 저장소의 파일을 업데이트하고 Actions 빌드가 성공하는지 확인합니다.
2. Hostinger 서버를 Stop하고 백업합니다. 특히 `world*` 및 `plugins/SMP` 폴더를 보존합니다.
3. 기존 `plugins/SMP-1.19.4.jar`만 빌드된 JAR로 교체합니다.
4. 재시작 후 `/version SMP`에서 `1.29.0`을 확인합니다.

주의: 소스 ZIP은 JAR 파일이 아닙니다. Maven/GitHub Actions 컴파일 및 게임 내 동작 검증은 별도로 필요합니다.
