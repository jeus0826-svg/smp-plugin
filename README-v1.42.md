# SMP v1.42 수정 내역

- 날카로움 X / 보호 X 인챈트 책을 호환되는 장비에 모루로 적용할 수 있도록 수정
- 같은 레벨 보호/날카로움 V 이상 합성: V+V 50, VI+VI 60, VII+VII 70, VIII+VIII 80, IX+IX 90 레벨
- 일반 모루 비용은 39로 강제 설정하지 않음; 최대 비용 제한을 해제하도록 처리
- 신호기를 직접 회수하거나 제거하면 24시간 유예기간 경과 시 나약함 다시 적용
- 적이 120초 신호기 점령을 완료하면 소유 팀 병합 후 팀 색상 갱신

주의: 팀 병합은 신호기를 **적이 점령하여 파괴**한 경우에만 적용됩니다. 소유 팀이 직접 회수하면 병합되지 않습니다.
컴파일 및 실제 게임 테스트가 필요합니다.
