# SMP v1.34 — Paper/Spigot 1.19.4, Java 17

v1.33 기반으로 다음 세 기능을 제거했습니다.

1. 팀 공유 창고 (`/teamstorage`, `/teamchest`, `/팀창고`) 명령어와 54칸 창고 및 관련 저장·불러오기 코드
2. 신호기/팀 시작 위치를 강제하는 커스텀 사망 후 리스폰 처리 — 이제 기본 마인크래프트 리스폰 동작 적용
3. 망원경 우클릭 적 추적, 불꽃 표시, 3분 쿨타임

다른 기능(팀, 신호기, 구매 가격, 24시간 나약함, 전투 등)은 v1.33 소스에서 유지했습니다.

## 중요: 기존 팀 창고 물품
기존 `plugins/SMP/state.yml`의 `teamChests` 데이터는 이번 버전에서 불러오지 않으며, 저장 시에는 해당 데이터가 제거될 수 있습니다. 업데이트 전에 `plugins/SMP` 폴더를 백업하세요. 공유 창고에 물품이 남아 있다면 **기존 버전에서 먼저 꺼내세요.**

## 빌드
GitHub에 소스 업로드 → Actions 성공 → Artifacts ZIP 안의 `SMP-1.19.4.jar` 설치. 서버를 종료하고 기존 JAR만 교체하세요. `plugins/SMP` 폴더와 월드 폴더는 삭제하지 마세요.

컴파일/게임 내 검증은 별도 필요합니다.
