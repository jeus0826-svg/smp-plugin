# SMP v1.37 — Paper 1.19.4 / Java 17

`/smphelp`는 신호기 및 전투·특수 장비 규칙만 표시합니다. 게임 시작·팀 설정·팀 관리·재접속 안내는 표시하지 않습니다. 실제 명령어와 기능은 유지됩니다.

## 주요 기능
- 팀별 랜덤 시작 위치, 팀 지정 및 색상, 중간 합류
- 신호기 설치 24시간 제한 및 미설치 시 나약함
- 신호기 활성화 시 같은 차원 500블록 내 팀원에게 성급함 III
- 신호기 구매 가격 10, 20, 30... 다이아몬드
- `/beacontp` 신호기 귀환, 침입 경보
- 보호 X 방어구 체력 및 이동속도 효과, 날카로움 X 검 공격속도 효과
- `/smphelp` 게임 규칙 안내

## 설치
GitHub에 소스를 업로드한 뒤 Actions에서 빌드합니다. 서버를 종료하고 백업한 뒤 JAR만 교체합니다. `plugins/SMP` 데이터 폴더와 월드 폴더를 유지하세요.

소스 코드 수정본이며 컴파일 및 실제 게임 테스트는 아직 수행하지 않았습니다.
