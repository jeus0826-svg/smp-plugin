# SMP v1.35 — Paper 1.19.4 / Java 17

v1.34 기반 변경 사항:

- 활성화된 팀 신호기에서 같은 차원의 반경 500블록 내 같은 팀 플레이어에게 성급함 III 적용. 기존 v1.34에도 해당 효과 로직이 있었으며 v1.35에서는 **최초 활성화 시 팀 안내 메시지**를 추가했습니다.
- `/smphelp` 명령어로 전체 SMP 규칙과 커스텀 기능을 게임 채팅에 출력합니다.
- v1.34에서 제거된 팀 공유 창고, 커스텀 리스폰, 망원경 추적은 복원하지 않았습니다.

주의: 신호기 바로 위의 방벽은 바닐라 신호기 광선을 막아 활성화를 방해할 수 있습니다. 실제 서버에서 신호기 활성 상태와 효과를 반드시 확인하세요.

## 설치
GitHub에 소스 업로드 → Actions 성공 확인 → Artifacts의 JAR을 다운로드 → Hostinger 서버 중지 및 백업 → 기존 플러그인 JAR만 교체. `plugins/SMP`와 월드 폴더는 삭제하지 마세요.

컴파일 및 실제 게임 검증은 아직 수행하지 않았습니다.
